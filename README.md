# Banking Backend System

A RESTful banking backend built using **Node.js, Express.js, and MongoDB**, designed to handle secure banking operations and transaction management.

### Features
- JWT-based authentication and authorization
- User and bank account management
- Secure money transfers
- Transaction processing
- Double-entry ledger system
- MongoDB transactions for data consistency
- Idempotency support for transaction safety
- Docker containerization
- CI/CD automation with GitHub Actions

### Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Token (JWT)
- Docker
- GitHub Actions

### Project Goal
To build a reliable and maintainable banking backend while implementing real-world backend engineering concepts, secure API development, transaction consistency, and containerized deployment.
